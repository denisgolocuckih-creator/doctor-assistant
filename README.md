# Автоматизированный справочник врача-терапевта

Интеллектуальная система поддержки принятия врачебных решений (СППВР).
Цифровой ассистент врача-терапевта на рабочем месте.

---

## Проблема

Врач-терапевт ежедневно принимает десятки пациентов при жёстком лимите времени —
10–15 минут на человека. За этот срок нужно:

- собрать анамнез,
- проанализировать симптомы,
- учесть историю болезни,
- проверить совместимость препаратов,
- свериться с клиническими рекомендациями.

Постоянная когнитивная перегрузка приводит к врачебным ошибкам, выгоранию
специалистов и снижению качества медицинской помощи.

## Решение

Система берёт на себя рутинные процессы и помогает врачу быстро принимать
обоснованные решения на основе доказательной медицины.

Ключевые возможности:

- ввод жалоб голосом или текстом,
- автоматическое извлечение симптомов и структурирование данных,
- ранжированный список вероятных диагнозов с обоснованием,
- предупреждение об опасных симптомах (красные флаги),
- учёт возраста и пола,
- рекомендации по обследованиям,
- в перспективе — проверка лекарственных взаимодействий, чек-листы,
  шаблоны заключений, интеграция с МИС.

## Текущий статус

Прототип работает end-to-end: **ввод жалоб → анализ → результат**.
Логика реализована на правилах (rule-based). Следующий шаг — замена правил
на ML-модель дифференциальной диагностики.

## Технологический стек

**Текущий прототип:**
- Python 3.10+
- FastAPI
- Uvicorn

**Планируется:**
- PostgreSQL — хранение данных
- React + TypeScript — интерфейс врача
- Transformers, SpaCy — обработка медицинского текста
- ML-модели для дифференциальной диагностики
- Шифрование персональных данных (ФЗ-152)
